# Admin Board

**Admin Board** — это маленький frontend-проект, имитирующий рабочую панель управления заявками

Проект создан, чтобы показать навыки разработки интерфейсов на **React**: работу с компонентами, вкладками, фильтрацией, списками, состоянием и адаптивной вёрсткой

---

## Стек

* React
* TypeScript
* Vite
* Tailwind CSS
* CSS variables

---

## Запуск проекта

```bash
npm install
npm run dev
```
